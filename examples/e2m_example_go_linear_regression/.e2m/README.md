# .e2m – Explain2Me data

* `notes/` – shadow files for `// e2m :f <id>` comments in the code (`<id>` → `notes/<id>.md`).
* `sessions/` – recorded walkthroughs. Open the *Explain2Me* tool window, pick a session and press
  **Next ▶** (static replay, no debugger needed) or **Live replay** (re-runs it under the debugger).
