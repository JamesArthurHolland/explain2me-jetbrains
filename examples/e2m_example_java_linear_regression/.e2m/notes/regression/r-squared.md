# Step 4 – coefficient of determination (R²)

    R² = 1 − SSres / SStot

* SSres = Σ (y − ŷ)² = 2.4 – error left over after using the line.
* SStot = Σ (y − ȳ)² = 6 – error of always guessing the mean.

**R² = 1 − 2.4/6 = 0.6**: the line removes 60 % of the squared error. 1 would be a perfect fit,
0 means the line is no better than the mean.
